# kuramatool
なんとかマーケットのデータをアレするツール

## config.ini

```
[user]
user_id=ユーザ名メールアドレス
user_pass=パスワード
```


## Selenium

- Docker環境でSelenium server経由で使う
- VScodeのdevcontainer向け設定
- ローカルのブラウザで http://localhost:4444/ui/#/sessions を開く
- python selenium_test.pyをDocker内で実行
- sessionが増えるので📹アイコンを押すとVNCでブラウザが開かれているのがみられる
